# 页面与资料说明

## 当前展示

三个视觉区域保留：深墨色字形台、暖纸色字源故事、橄榄绿色字间联系。页面没有品牌 Logo、导航、宣传标语；内容从顶部直接开始。

左侧只有小尺寸“字库”“偶遇”。字形下方只有“拆笔”，点击显示彩色笔段和独立笔段；同一个按钮变为“合字”。默认不露出笔画列表。没有书写播放、速度、猜字、描写或收藏入口。

关系区固定展示关系图，不给用户展开/收起或筛选的选择。该区域已独立为 `模块/字间关系/关系面板.js / 关系面板.css`，接口见 `RELATIONS-MODULE.md`。

授权说明移到 `license.html`，主页底部用简短链接指向该页；完整字体文件及授权记录继续保留。

## 显示材料

默认起始字为“安”。安、宇、包、光已接入同一组平滑笔段，合字/拆笔只改颜色；字库、故事对照和关系图也优先使用清理版。逐字操作及后续 agent 交接以 `GLYPH-CLEANUP.md` 为入口。

崇羲篆體覆盖 90/124 个样本，其余回退到 SVG；字体未裁剪或改作。拆筆的 SVG 来自实际样本，使用已有坐标，不来自崇羲字体。原始字图在故事的资料来源中可见。

本义、引申义、构形与部件说明来自现有资料。没有完整历史链的字只显示小篆与今字对照，不补造甲骨、金文、隶书图片或年代。

## 后续内容

`模块/字源故事/故事数据.js` 可按完整字形 ID（优先）或汉字编辑 `headline`、`source`、`timeline`。历史路径每项支持 `label`、`image` 或 `text`、`caption`、`source`；只在取得并核对材料后添加。

现有独立笔段可进一步做拼图；现有构件与形旁/声旁资料可做字族探索；研究素材中的象形、形似字可做主题合集。当前页面保持精简。

## 历史保存

原始研究工程在 `research/`，旧数据备份和临时预览在 `archive/`。带播放、描写、猜字等控制的上一版页面与代码保存于 `archive/interface-with-controls/`，当前运行不再加载这些功能。
