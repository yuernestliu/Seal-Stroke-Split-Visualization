# 小篆与《说文解字》：学生查阅指南

整理与核查日期：2026-10-21。

这份指南用于给项目中的字形、字源故事和部件关系补充可追溯的文献依据。先用小学堂查小篆字形，用港中文查《说文》释文及形义解释，再用古籍影像核对具体版本；遇到简繁、异体或字头对应问题，查教育部《异体字字典》。

这里的数据库、电子文本、古籍影像和现代字体分别服务于字形比对、文字检索、版本校核和排印展示。学生记录资料时应标明实际使用的是哪一种。

## 先用这两套字库

### 1. 小学堂：查字形、编号和重文类别

小学堂小篆库最适合先做逐字比对。简易查询支持字形、字号、页码；进阶查询还支持《说文》卷数、部首、小篆部件等。官方页面列出9,831个字头、11,101个字形（本次核查时的收录数）。

使用时同时查看[简介](https://xiaoxue.iis.sinica.edu.tw/xiaozhuan/About/About)、[凡例](https://xiaoxue.iis.sinica.edu.tw/xiaozhuan/Example/Example)和[参考书目](https://xiaoxue.iis.sinica.edu.tw/xiaozhuan/Bibliography/Bibliography)：

- 字形采用「北师大说文小篆」字型，字头顺序以《说文解字》为依据；它提供的是整理后的字形资料。
- 字号参照《说文解字诂林正补合编》，不能只凭编号就认定与本项目字形ID相同。
- 每个字形保留「说文」「说文或体」「说文古文」「说文籀文」「说文篆文」「说文俗字」「说文奇字」等类别。录入时保留类别，便于比较同一字头下的不同字形。

### 2. 港中文：读释文、查形义与注释

[汉语多功能字库首页](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/)适合从现代字进入，结合古文字字形和形义通解整理故事。[《说文》全文索引](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/shuowen.php)则适合查“从某”“某声”等原文以及徐铉、徐锴注释。

全文索引的官方简介说明，其电子文本在施谢捷提供的电子档基础上重新校对，主要依据中华书局1963年、2013年影印陈昌治校刊本，并兼收《说文新附》及《说文解字系传》增补字头。引用时记录条目所标来源和页码，可以把网页说明追溯到所据版本。

此前收集的[港中文原链接](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/ancient.php?start=10)继续保留（本次该具体页面访问超时，未完成页面内容核对；字库首页及《说文》全文索引已读取）。遇到原链接无法打开，先从首页或全文索引进入。

## 《说文解字》及段注的版本来源怎么写

文献出处同时记录**原书与版本**、**提供查阅的网站与条目地址**。例如“《说文解字》某部某字，某版本第某页；通过港中文《说文》全文索引查阅，访问日期……”；只写“来源：百度／某字典网站”不足以让其他同学复核。

可从已核实的以下书目或目录继续查找：

| 原书或版本线索 | 线上依据与用途 |
| --- | --- |
| 许慎《说文解字》，香港：中华书局，1972年 | 小学堂官方参考书目列出的版本之一；用于理解该库的文献依据 |
| 杨家骆主编《说文解字诂林正补合编》，全十二册，台北：鼎文书局，1994年 | 小学堂官方参考书目；其凡例说明字头编号参照此书 |
| 中华书局1963年、2013年影印陈昌治校刊本 | 港中文《说文》全文索引简介说明的主要校对依据 |
| 《说文解字》《四部丛刊初编》本；段玉裁《说文解字注》 | 中国哲学书电子化计划的书名目录列有文字与影像入口；引用时进一步填写实际选用版本及页码 |
| 段玉裁注《说文解字注》，商务，1949年初版，分册 v.10，馆藏编号004638006 | 台湾华文电子书库的具体书目示例；读影像时记录书内卷次和页码，网站的分册 v.10 不直接当作“卷十” |

《说文》原文、徐铉／徐锴注、段玉裁注及网站的现代解释分别标注，便于判断某句话是谁的解释。古籍电子文本用来检索，引用中的字形、异体、标点及疑难字再对照所据书影。

## 学生逐字怎样使用

先从认领的5—20字中选一个字，例如“安”，按下面顺序整理一份可复核的来源记录：

1. **对齐字形。** 保留本项目完整字形ID，在小学堂查字头与重文类别，确认比较的是同一类字形；记录对应与不一致之处。
2. **读原文。** 在港中文《说文》全文索引查该字，记录部首、原文、来源类型与页码，再读形义通解。整理短故事时区分原文引述、注家解释和自己的概括。
3. **核对差异。** 若简繁或异体对应有疑问，查教育部《异体字字典》的文献依据；若释文或版本有歧义，再查古籍影像。
4. **留下证据。** 在逐字记录或提交说明中附条目链接、字头／编号、版本／页码、访问日期、核对者及待核问题；几何清理和构形判断分别登记状态。

建议每条来源至少保存下列信息（可先写入逐字附注或PR说明，字段名仅供整理，不要求直接加入现有JSON接口）：

| 信息 | 填写内容 |
| --- | --- |
| 项目字形ID | 任务表中的完整ID，避免只写现代字 |
| 来源与链接 | 数据库名称和具体条目URL；若只有检索页，补查询字与编号 |
| 材料类型 | 字库字形／《说文》原文／注释／古籍影像／现代字体 |
| 文献定位 | 原书、版本、卷／部、字头或编号、页码；尚未查到的写待核 |
| 引用与整理 | 原文摘录及自己的释读分开，并记下与本项目字形的对应关系 |
| 核对状态 | 访问日期、核对者、已核内容和待解决的问题 |

## 字体、图像与项目现有资料的来源

[崇羲篆体制作说明](https://xiaoxue.iis.sinica.edu.tw/chongxi/)介绍了依大徐本书写、对未收字转写等取形原则，可用于理解展示字体的来源。它和小学堂小篆库采用的「北师大说文小篆」应分别记录。项目现有崇羲字体的文件、版本和署名见[字体许可](../assets/fonts/LICENSE.md)，官方另有[下载入口](https://xiaoxue.iis.sinica.edu.tw/chongxi/download.htm)和[授权说明](https://xiaoxue.iis.sinica.edu.tw/chongxi/copyright.htm)。

图像或字体要随项目再发布时，按具体材料的授权处理。崇羲篆体官方采用CC-BY-ND-3.0-TW-or-later，要求署名并禁止修改本著作；台湾华文电子书库页面标明仅供网络浏览、禁止转载，学生可先引用条目和书目链接。

本页新增的是外部查阅与校核来源。现有原图继续按[字库说明](../字库/README.md)和[整合来源记录](../docs/整合来源.json)追溯到已有项目材料；外部字库的逐图对应关系待实际比对后再登记。
