# 500字处理结果规范（学生首要任务）

每字使用完整字形ID，建议放在本目录下同名文件夹。当前只建立交付约定，不表示已生成500字成果。

| 文件 | 内容 |
| --- | --- |
| source.json | 原图路径、内容哈希、宽高、来源版本、处理方法和参数 |
| mask.png | 清理后的字形掩膜，保留原件；修补有记录 |
| outline.svg | 真实矢量轮廓，明确viewBox，与原图对齐；不能以嵌入PNG代替矢量路径 |
| skeleton.json | 骨架节点、边、曲线／采样与闭环；端点和交点有稳定ID；保留像素坐标与归一化变换 |
| overlay.svg | 供复核的叠加图，可带原图背景；它与outline.svg用途不同 |
| review.json | outline／skeleton各自状态，负责人、复核人、日期、问题与修订记录 |

统一坐标：原图左上为原点，x向右、y向下，单位为原图像素；归一化或缩放时保存可逆映射。骨架不是一张缩略PNG：节点和曲线必须可以重用，纯闭环也要有表示，不能在端点检测时丢失。

复核重点是细笔、毛刺、孔洞、连通、交叉与路径拟合是否符合原图。低分辨率下无法判断的细节应记录歧义，平滑不能恢复不存在的信息。outline_reviewed和skeleton_reviewed分开记录。

后续组成单元用独立记录引用骨架边／区域及共享unit ID，保留上下、左右、包围、接触、交叉等关系；不要把单字节点ID当成跨字单元词表。

安、宇、包、光现有平滑记录仍在data/cleaned-glyphs/，请引用它们，避免并行维护两套几何。首批先交10个示范包，标准确认后完成全部500字。详细任务见docs/项目计划.md。
