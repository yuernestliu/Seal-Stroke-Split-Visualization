接下来，按这个顺序做

01　完成500字高质量字形首要任务

先交10个示范样本，再覆盖全部500字。每字保留原图、清理掩膜、真实矢量轮廓和复核记录，不能只把PNG放进SVG。

02　建立骨架与拓扑入口几何标准

保存节点、边、曲线、闭环及坐标映射，能叠回原图检查细笔、连通和交叉。骨架是几何基础，不自动等于笔画或笔顺。

03　拆成可复用组成单元不必先恢复笔画

可先用经核对的部件先验，再尝试骨架子图；同类单元跨字共用ID，保留上下、左右、包围和连接关系。

04　补故事，连成网三个模块并行

每个故事附出处；每条联系说明依据。字形、字源故事、字间关系各自维护，通过字形 ID 对齐。

05　接入梯径，再扩展后续目标

先固定单元词表和结构编码，评估先验与几何路线。现有序列接口需要适配；500字验收后进入2000字，最后覆盖全部。

最后想做成什么？

一个本科生打开就愿意玩的小篆探索界面。

  1. 字形能看清，也能拆开；合字和拆分使用同一套几何。
  2. 故事短而有趣，能追溯到材料。
  3. 字与字之间可以顺着部件、形态和演变继续探索。

现在的部首与 IDS 关系是起点。更远的目标，是让梯径从结构中发现联系。

认领任务：先读仓库 README 与学生计划，再在500字任务表填写负责人和复核人。原图、轮廓、骨架、部件和故事分别记录进度；故事与文献可以并行整理。

查字形与《说文》，从这里开始

小学堂小篆库查字形、编号与重文；港中文汉语多功能字库查形义，《说文》全文索引查释文与注释；教育部《异体字字典》核对异体。
