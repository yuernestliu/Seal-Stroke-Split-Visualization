# 原包字形清边与同形拆笔

当前网站默认字形来自崇羲篆體，拆笔来自原包；两种笔形不同。本次只制作方法对照，未改默认界面。

对照页：`public/proofs/clean-strokes.html`。生成命令：`python3 scripts/preview_clean_strokes.py`。示例为宇、包、光，几何结果见同目录 JSON。

推荐路线是沿用原包的笔段与坐标：

1. 保留已有的笔段数量、端点与坐标系。
2. 平滑每个笔段的中心线，将像素阶梯转为二次曲线路径。
3. 依据原图估计笔宽，抑制毛刺造成的宽度起伏，以圆角、圆端点绘制。
4. 默认整字叠加同一组路径；拆笔只改颜色或显示位置，不替换另一套字形。

三个样例已验证合字和拆笔的路径完全一致、原端点不变。线条宽度与局部曲率经过处理，不代表与原图的像素轮廓完全相同，也不新增文字学构形判断。

全量处理前需核对交叉点、闭合圈、短笔及原拆分错误；可能需要少量逐笔参数或人工修正。原始图像与拆分记录应保留，清理结果单独输出。

另一条路线是使用崇羲篆體：原包与字体的形状不同，需重新标注笔段，或先做字形配准再映射原有笔段，并逐字人工核对。仅修改 font-family 不能把现有分段准确移到另一套笔形上。
